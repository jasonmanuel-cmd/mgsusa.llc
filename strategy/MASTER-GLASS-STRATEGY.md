## Local SEO foundation

### Google Business Profile operating system

1. Verify ownership, use the exact business name **Master Glass Solutions**, exact Boerne address, 210-370-3700, and the website URL.
2. Select one accurate primary category after a live eligibility review; add only truthful secondary categories.
3. Write a locally specific description that names commercial/residential glass, core services, Boerne, San Antonio, 20+ years, and 24/7 emergency support—without keyword stuffing.
4. Add each real service with natural descriptions and the appropriate service-page URL.
5. Add original exterior/team/project photos and short video; preserve metadata where useful but do not rely on EXIF for ranking.
6. Ask for reviews systematically after completed work. Never gate reviews, incentivize positive reviews, or write review copy for customers.
7. Respond to every review with human, specific language. Mention the service naturally only when it is part of the reviewed job.
8. Publish GBP updates for genuine project completions, service explainers, and emergency-support information.

### On-page SEO rules

| Element | Rule / formula |
|---|---|
| Title tag | **[Primary service] in [Core city / city pair], TX \| Master Glass Solutions**. Keep it specific, human, and generally within ~50–60 characters when possible. |
| Meta description | **[Service] for [buyer/property] in [city]. [Specific scope / differentiator]. [Clear CTA or urgent action].** Aim for ~145–160 useful characters, not a keyword list. |
| H1 | One per page. State the service/outcome, not just a keyword. Include location naturally in eyebrow, intro, or sentence near the H1. |
| H2s | Use direct task questions and decision topics: What is it? When do you need it? How it works. Cost factors. Related services. FAQs. |
| H3s | Name sub-services, individual steps, comparison elements, or project types. Never use headings solely for visual size. |
| First 100 words | Identify business/service + local relevance + buyer outcome in a simple sentence. |
| Body copy | Use terms customers use, but only where explanatory. No density target; semantic completeness beats repetition. |
| URLs | Lowercase, durable, service-led slugs: `/storefront-glass`, `/boerne-tx`. Preserve redirects from old Wix URLs. |

### Technical SEO / Core Web Vitals checklist

- Serve HTTPS; force one canonical host and redirect all alternatives with 301s.
- Map existing URLs such as legacy commercial/residential pages to the closest new equivalent; do not abandon old indexed routes.
- Generate and submit `sitemap.xml`; retain `robots.txt`; inspect index coverage in Search Console.
- Render crucial content as HTML, not client-only JavaScript. This delivered build is static HTML.
- Preload only the actual LCP hero image; serve responsive AVIF/WebP/JPEG sources in production; set width/height or aspect ratio to prevent CLS.
- Use `loading="lazy"` for below-fold real images and never lazy-load the LCP image.
- Self-host or carefully subset fonts; use system fallbacks; avoid render-blocking animation libraries.
- Keep forms server-side validated, CSRF protected, rate limited, spam protected, and accessible. Use an endpoint rather than a static-only form action at launch.
- Configure GA4/GTM, call-click events, form-start/form-submit, emergency CTA, source/UTM capture, consent mode, and CRM attribution.
- Add a privacy policy, terms if needed, accessibility statement, 404 page, 301 redirect map, and error monitoring.
- Test keyboard navigation, focus states, contrast, screen-reader labels, form errors, mobile tap targets, and 320px width.
